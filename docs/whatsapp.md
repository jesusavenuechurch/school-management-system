# WhatsApp message templates

The templates to submit in Meta's WhatsApp Manager (Business Manager →
WhatsApp Manager → Message templates) before the platform starts messaging.

Meta only lets a business start a conversation with an approved template.
Free-form messages are allowed only within 24 hours of the person last
messaging you, so everything the school sends first (absences, fees,
reports, invites) must be one of these.

## Before you submit

- **Names** are lowercase with underscores. The `key` column is the
  `notification_templates.key` the code uses; the Meta name is what you
  type in WhatsApp Manager. Keep them exactly as listed so the code can
  find them.
- **Brand name:** the platform name isn't final, so templates say
  `[Platform]`. Replace it with the real name before submitting. Meta
  rejects templates whose wording changes after approval, so decide on the
  name first.
- **Variables** are numbered `{{1}}`, `{{2}}`… Meta asks for a sample value
  for each one; use the samples given.
- **Categories matter.** Utility templates must be about something the
  recipient is already involved in (their child, their invoice, their
  account). Anything promotional is Marketing, costs more, and parents
  must have opted in. School notices are the grey area: keep them factual
  (dates, closures, meetings), never adverts.
- **Language:** submit English (`en`) first. Check whether Sesotho is in
  Meta's supported language list at the time you submit; if it is, add a
  Sesotho translation under the same template name.
- **Buttons with links** point to the platform. Use a dynamic URL button
  with base `https://[your-domain]/` and a `{{1}}` suffix, so each message
  can link to its own page (a signed, expiring link generated by the code).
- **Opt-out:** every message to a parent respects
  `users.whatsapp_opted_out_at`. Utility templates don't need an opt-out
  line, but you can add a quick-reply "Stop messages" button; the webhook
  then sets the opt-out.

## Templates

### 1. Sign-in code

|           |                                              |
| --------- | -------------------------------------------- |
| Key       | `auth.login_code`                            |
| Meta name | `login_code`                                 |
| Category  | Authentication                               |
| Used for  | One-time code to sign in or reset a password |

Authentication templates use Meta's fixed wording; you only choose options:

- Code delivery: **Copy code** button
- Add security recommendation: **yes** ("For your security, do not share
  this code.")
- Add expiry time: **yes, 10 minutes**

Sample: `482913`

## When templates are approved

1. Add your credentials to `.env`:

    ```
    WHATSAPP_PHONE_NUMBER_ID=
    WHATSAPP_BUSINESS_ACCOUNT_ID=
    WHATSAPP_ACCESS_TOKEN=
    WHATSAPP_WEBHOOK_VERIFY_TOKEN=
    ```

2. Seed one `notification_templates` row per template above (with
   `school_id` null, so every school uses them), storing the Meta name and
   the order of the variables.
3. Point Meta's webhook at the platform so delivery and read receipts, and
   "Stop messages" replies, update `notification_messages` and the opt-out.

Messages to parents are only sent for **verified** schools.
